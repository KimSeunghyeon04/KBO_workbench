# 구질 유사 매치업·타자 효과·진입각 구현

2026-09-20. A09의 구질 유사 표본과 타자별 기대 반응, A03/A05의 원천 진입각을 구현했다.
추가 외부 자료나 DB migration 없이 현재 수집 자료와 기존 A10 모델을 사용한다.

## 구현과 권위

- `contracts/matchup-model.ts`, `pitch-angles.ts`가 strict 입출력 계약을 소유한다.
- `game-core`의 `matchup-similarity`, `matchup-effects`, `matchup-training`, `matchup-model`은
  거리·축소 효과·학습·화면 요약을 나눈 순수 계산 모듈이다. A10의 전처리와 평가 함수를 재사용한다.
- `pitchApproachAngles`는 기존 궤적 검증·통과 시간 계산을 사용한다. `pitch-angles`가 표본과
  구종/경기별 안정적 평균·분산을 집계한다. 브라우저에 별도 물리 계산기를 두지 않는다.
- 각 repository는 읽기 전용 repeatable-read snapshot에서 필요한 선수를 읽는다. 계산 전에
  DB 연결을 반환하며 API는 기존 bounded computation worker에 계산을 맡긴다.
- 새 매치업 모델은 A10 원천 manifest 및 모델 hash와 결합된 불변 파일이다. 저장은 기존
  workspace writer lock과 atomic write를 사용한다. 원장·sealed facts·기존 모델은 수정하지 않는다.

화면은 요청 시에만 새 패널을 읽고 근거/결과 표는 25행씩 표시한다. 기존 관측 매치업 API는 유지한다.
구현 상세는 [A09](features/09-matchups.md), 각도 정의는 [A03](features/03-pitcher-profile.md)에 있다.

## 학습과 검증 기준

`pnpm analysis:train-matchup --through 2024`로 현재 원천의 A10 모델을 읽고 학습한다.
`--dry-run`은 저장하지 않는다. `--base-workspace`로 원본 모델과 출력 workspace를 나눌 수 있다.
전체 자료 읽기와 학습은 하나의 maintenance worker에서 수행한다. 부모 프로세스로 원시 투구를
복제하지 않으며 실패·취소·30분 제한에서는 모델 포인터를 공개하지 않는다.

2020–2022 → 2023, 2020–2023 → 2024의 두 fold에서 보정·표준화·타자 효과를 과거로만 적합한다.
A10에서 선택한 모형 종류/규제 설정을 각 fold의 과거 자료로 다시 적합해 타자 효과 추가 전후를
비교한다. 2024까지 최종 적합하고 2025는 선택에 사용하지 않은 평가로 남긴다. 입력 역순과
2025 결과/특성 변경이 학습·선택 결과를 바꾸지 않는 회귀 테스트를 포함한다.

타자 효과는 기존 확률의 logit에 더하는 규제된 offset이다. 양성/음성 한쪽만 있는 타자도 유한한
값으로 축소하며 수렴·20표본·5경기를 만족하지 못하면 개인 확률을 제공하지 않는다.
두 fold의 log loss 개선, 경기 단위 bootstrap 95% 구간 상한 < 0 및 기존 하위집단 gate를 요구한다.
하위집단 gate는 1,000표본 이상 집단의 2% 초과 악화를 거부한다.

투타 조합의 예측 정확도 보장은 아니다. 선수 이력이 부족하면 목표별로 미준비 상태가 된다.

구질 거리 반경 0.5/1/1.5는 단순 조건 필터와 비교한 스윙 예측 개선 gate를 통과하지 못했다.
따라서 반경 1의 탐색용 관측 표본만 제공하며 `validatedImprovement=false`를 명시한다.
좋아 보이는 결과가 나올 때까지 반경을 넓히거나 이를 타자 효과 모델의 성능으로 설명하지 않는다.

## 진입각 점검

모든 시즌을 중간면 17/24 ft로 계산했다. 실제 시즌별 최다 투구 투수 표본에서 사용 수는 다음과 같다.

| 시즌 | 실제 투구 | 각도 사용 | tracking 누락 | 유효 궤적 아님 |
| ---- | --------: | --------: | ------------: | -------------: |
| 2020 |     3,525 |     3,494 |             2 |             29 |
| 2021 |     3,405 |     3,366 |             3 |             36 |
| 2022 |     3,003 |     2,945 |             5 |             53 |
| 2023 |     2,988 |     2,872 |           104 |             12 |
| 2024 |     3,124 |     3,108 |             8 |              8 |
| 2025 |     3,037 |     2,995 |             1 |             41 |

해당 표본의 원천 면은 2020–2023 앞면, 2024–2025 중간면이었다. 2025 전체가 중간면이라는
뜻은 아니다. 혼합 면 불변성은 별도 합성 테스트에서도 확인했다. 궤적의 기하학적 계산을 검증한
것이며 독립 측정 장비와의 실측 정확도 비교나 진입각 구장 편향 교정은 포함하지 않는다.

## 성능과 재현 자료

최종 학습 96.09초 중 읽기 41.96초, 적합 53.62초, 저장 0.51초였다. 100ms 간격 최대 관측 RSS는
3.47GiB였다. 원시 입력을 다른 worker로 복제하던 첫 실행의 4.71GiB에서 약 26% 줄었으며 최종
모델 hash가 동일했다. 실행 시점/캐시 차이가 있으므로 시간 차이를 통제된 속도 개선으로 해석하지 않는다.

모델 파일은 약 957KiB다. 온라인 요청은 재학습하지 않고 선택 선수 입력에 고정 모델을 적용한다.
선수 키 manifest와 투구의 TypeBox 검사는 미리 컴파일한 검증기를 재사용하되 매 요청의 원천
검증과 canonical hash를 유지한다. TTL로 원천 변경을 놓치는 캐시는 추가하지 않았다.

원 학습 로그·30회 조회·응답 hash·6시즌 각도 표본은
`analysis/deployment/20260920-matchup/`에 남긴다. 조회 30회 결과는
[성능 기록](performance.md#구질-매치업과-원천-진입각-추가)에 있다.

## 품질 검증

lint·format·typecheck·schema check·build와 기본 테스트 841개가 통과했다. PostgreSQL 통합
테스트는 별도 격리 DB에서 70개를 실행했다. 새 매치업의 선수별 입력과 학습 입력 일치,
원천 revision 변경 시 모델 미준비, 진입각 원천 해시 변경도 포함한다.
HTTP parser의 별도 prototype을 가진 query는 strict decode 뒤 일반 객체로 복사하여 해시한다.
같은 입력을 DB 회귀 테스트에 넣어 일반 객체 조회와 응답 전체가 같은지 확인한다.
격리 Compose E2E에서 새 진입각·매치업 패널과 390/1440px 화면, 기존 import·replay·교정·
journal recovery·backup/restore가 통과했다. 운영 데이터와 실제 Naver 호출은 사용하지 않았다.

기존 컴파일 성능은 558이벤트 200회 평균 5.529ms / p95 8.770ms, 재생 구성 500회 평균
0.970ms / p95 1.437ms로 기존 기준을 유지했다.

## 운영 반영

검증된 빌드와 위 모델을 로컬 운영 서비스에 반영했다. 실행 중 수집·적재·기록정정 작업이 없는
것을 확인하고 API/web writer를 정지한 뒤 기존 workspace 저장 경로로 모델을 공개했다.
추가 DB migration은 없다. 직전 API/web 이미지 태그와 기존 paired backup을 보존했다.

HTTP 검사 21건에서 strict 계약·모델 준비 상태·검증 사본과의 응답 hash를 확인했다.
모델 없는 과거 시즌과 정규시즌 외 요청, 기존 매치업·투수 변화·구종 기대 효과·11회 승리확률,
새 두 endpoint의 동시 요청도 정상 응답했다. 소수 동시 요청 성공을 부하 상한으로 해석하지 않는다.

운영 브라우저에서는 2025 로건–송성문 매치업의 세 목표 준비 상태, 구질 유사 992구·132경기·
136투수와 직접 중복 20구, 코스별 기대 확률을 확인했다. 투구 움직임/투수 변화 화면 양쪽에서
3,037구 중 2,995구의 진입각과 제외 합계를 확인했고 경기 표의 페이지 이동도 동작했다.
점검한 브라우저의 console warning/error는 없었다.

| 운영 HTTP 조회             | 재시작 후 첫 조회 | 이후 4회 범위 |
| -------------------------- | ----------------: | ------------: |
| 구질 매치업·타자 기대 반응 |           1,924ms | 1,292–1,609ms |
| 원천 진입각                |             184ms |     177–218ms |

이는 HTTP 왕복을 포함한 관측 범위이며 p95가 아니다. 온라인 매치업의 1초 목표는 아직 남아 있다.
새 모델의 적용 시즌은 2025이고, 과거 시즌의 타자 기대 확률은 해당 학습 모델을 준비해야 한다.
원천 진입각은 2020–2025의 수집된 궤적에서 제공한다.

운영 API/web/DB는 healthy이며 배포 후 점검 로그에 warning/error와 5xx가 없었다.
4,693개 sealed revision의 document/projection hash 목록과 기존 current/active 파일 11개는
배포 전후 동일하다. 경기 원장·최종 경기 결과를 변경하지 않았다.
