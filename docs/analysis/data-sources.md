# 분석 자료와 입수 범위

확인일: 2026-09-20. 수치는 이번 설계 직전의 로컬 DB 읽기 전용 조회 결과다.
향후 적재·정정에 따라 바뀌며 운영 API에 상수로 넣지 않는다.

### 조회에 사용할 실제 구조

- `analytics.current_game_revisions`: 날짜·구장·시즌·revision·document hash.
- `analytics.current_pitches`: 실제 투구·스윙/헛스윙·카운트·구종·구속·tracking·존·선수 identity.
- `analytics.current_plate_appearances`: 결과·완료 여부·공식 PA/AB/BF·최종 기록 귀속.
- `analytics.current_plays`, `current_play_events`: atomic before/after 상태와 이벤트 연결.
- `analytics.current_runner_movements`: 주자 이동·결과·이유·책임 투수.
- `analytics.current_player_game_batting/pitching/baserunning`: compiler가 만든 경기별 집계.
- `workbench.tracking_observations`, 경기 roster/team snapshot, `baseball.game_final_states`:
  current game/revision을 명시적으로 연결해 필요한 보완 필드만 읽는다.

`database/examples/`의 시즌 성적 SQL은 정의 확인용 출발점이다. 날짜·경기 종류를 제한할 때는
이미 전체 시즌을 합산한 view를 다시 잘라 쓰지 않고 current player-game/PA/pitch에서 집계한다.
특히 현재 시즌 투수 view의 ER 합계는 null 누락 이닝을 별도로 제한하지 않으므로 A02에서 표본을 맞춘다.

공식 일정의 웹 내부 조회 경로는 버전 보장이 있는 공개 API와 같지 않다. 실제 연결 단계에서 현재
제공 방식·사용 조건과 6개 시즌의 매칭률을 다시 확인한다. 별도 계약이나 대량 수작업이 필요하면
외부 자동 취득은 빼고, 검증 가능한 기존 증거와 소량의 명시적 참고자료만 사용한다. 미분류 경기를
정규시즌으로 추정해 채우지 않는다. 분석 요청 중 외부 사이트를 호출하지 않는다.

### 날씨의 사용 범위

ERA5는 관측을 결합한 격자 재분석 자료이며 구장 안의 실제 바람·온도를 직접 측정한 값이 아니다.
야외 구장만 분석하고 돔 내부 조건을 바깥 날씨로 대체하지 않는다. 경기 시작 시간이 확정되지 않으면
시간별 조건 분석에서 제외하고 일별 보조 집계만 가능하다고 표시한다. 재분석 날씨를 경기 전 예보로
간주하지 않는다. 무료 이용 조건은 [제공자 안내](https://open-meteo.com/en/pricing)를 확인한다.

시간별 날씨는 API 자체는 확인했으나 현재 원장에는 예정 시각만 있어 이번 구현에서 제외한다.
확정 시각을 수작업으로 보충하거나 예정 시각으로 대체하지 않는다.

## 3. 범위에서 제외하는 기능

| 기능                                          | 제외 이유                                                                             |
| --------------------------------------------- | ------------------------------------------------------------------------------------- |
| EV/LA 기반 xwOBA·배럴·강한 타구               | 현재 구조화된 타구속도·발사각 없음; 6개 시즌 전 경기의 간편한 원자료 입수 경로 미확인 |
| 실측 RPM·회전축·회전효율·seam 효과 분해       | 회전 관측이 없고 궤적만으로 같은 의미의 실측값을 복원할 수 없음                       |
| 실제 릴리스·익스텐션·신체 동작                | 50ft 계수는 릴리스나 신체 tracking이 아님                                             |
| OAA/정밀 수비 범위·주력                       | 수비수·주자의 시공간 위치 자료 없음                                                   |
| 목표 대비 제구·정밀 포수 프레이밍             | 목표 위치·포구 동작·일관된 추가 식별 자료 없음                                        |
| 부상 예측·피로 진단                           | 등판 기록만으로 필요한 신체·의료 정보를 대체할 수 없음                                |
| 전 선수 연령 성장곡선·완전한 좌우투 리그 순위 | 전체 대상의 보조 프로필 확보 미검증; 이번 구현의 필수 의존성에서 제외                 |
| 전체 리그 GB/FB/LD 순위                       | 현재 유형 결측이 크고 결측이 무작위라는 근거 없음                                     |

[KBO 방송 시각화 안내](https://www.koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=11473)는
RPM·타구속도·발사각의 방송 제공을 설명한다. 공개 표시 사실만으로 과거 전 경기 원자료를 일괄
입수할 수 있다고 판단하지 않는다. 추후 별도 자료가 생겨도 이 계획의 기능에 조용히 섞지 않고 범위를 재검토한다.

## 4. 보완 자료 도입 체크

외부 자료를 실제 기능에 넣을 때에는 다음을 해당 기능 PR에 기록한다.

1. 기존 자료만으로 부족한 정확한 필드와 사용할 분석.
2. 작은 실제 응답을 확인한 날짜, 요청 조건, ID 매칭 방법, 누락·충돌 처리.
3. source URL·내용 hash·정규화 버전·채택 선택의 보존 방식.
4. 외부 취득 없이 재현하는 sanitized fixture와 실패 테스트.
5. 자동 취득이 어려워졌을 때 빠지는 보조 기능과 계속 작동하는 핵심 기능.

현재 숫자만으로 수집 완전성을 선언하지 않는다. A01은 같은 SQL 정의를 재사용 가능한 품질 조회로
만들고 실제 query·input hash와 함께 결과를 제공한다.
