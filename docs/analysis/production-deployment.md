# 분석 기능 운영 배포 기록

2026-09-20, 로컬 운영 서비스 `http://127.0.0.1:8080`.
검증 사본에서 확인한 코드·공식 경기 분류·모델을 운영 서비스에 반영했다.

이 문서는 최초 배포 시점의 기록이다. 이후 11회 승리확률 지원과 조회 개선은
[후속 개선 기록](2026-09-20-improvements.md)을 따른다.

## 데이터와 모델 반영

- 실행 중 수집·적재 작업이 없는 것을 확인하고 API/web writer를 정지했다.
- `.backups/kbo-workbench-20260920T091655431Z`에 PostgreSQL dump와 workspace ZIP을
  함께 만들고 manifest의 SHA-256과 대조했다. 원문·교정 이력 약 8.8만 파일을 포함한다.
- `0011_game_competition`, `0012_competition_game_links`를 적용했다.
  analytics/projection/registry/record correction 계약 `4/4/1/2`는 유지한다.
- 검증에 사용한 216개 공식 일정 원문을 다시 hash 검증·파싱하고, 운영 경기와 연결한
  분류 dataset hash가 검증 사본의 6개 시즌 hash와 일치하는지 먼저 dry-run했다.
  원문 저장과 분류 채택은 기존 workspace writer lock과 repository transaction을 사용했다.
- 모델 5개를 strict read한 뒤 운영 DB의 현재 manifest로 다시 확인했다. 기존 기능별
  workspace 저장 메서드로 공개했으며 검증한 모델 파일 hash와 모두 일치했다.
- 운영 경기 4,693개 중 정규시즌 4,316개, 시범 256개, 포스트시즌 86개, 미분류 35개다.
  배포 전후 모든 sealed revision의 ID·revision·document hash·projection hash 목록이 동일하다.
  현재 원장과 manifest인 `active`/`current`의 11개 파일도 백업의 해당 파일과 SHA-256이 같다.

적용 모델은 2024년까지 학습한 RE24, 카운트 RE, 승리확률, 구장 효과, 구종 기대 효과다.
이 파일들의 적용 시즌은 2025년이다. 2024년 등 다른 시즌의 학습 모델을 임의로 대신하지 않는다.
2025년 승리확률은 11회 규정 미지원 응답과 확정된 종료 결과를 유지한다.

## 기동과 점검

백업 파일은 정상 생성됐으나, 백업 스크립트가 기존 컨테이너를 재시작하는 단계에서 healthcheck
기다림이 실패했다. 원문 디렉터리 순회와 무결성 검사가 짧은 시작 유예를 넘을 수 있어 API의
`start_period`를 180초로 늘렸다. 새 서버는 준비 중 `/health/live` 200, `/health/ready` 503을
유지하다가 실제 검증이 끝난 뒤 준비 상태로 전환했다. 새 API/web 교체부터 readiness까지
58.63초였으며 API·web·DB 모두 healthy를 확인했다. 유예 시간 변경은 무결성 검사를 생략하지 않는다.

실제 HTTP 응답 32건에서 상태 코드와 TypeBox 계약을 검증했다. 성적·구장·구종 모델·배합·운용·
코스·타자 반응·매치업·주루·변화·품질·RE24·카운트 가치·승리확률·재생 manifest를 포함한다.
시범경기 제외와 모델이 없는 과거 시즌도 기대한 상태로 응답했고, 추가 동시 요청 2건도 성공했다.

실제 인앱 브라우저에서 분석 12개 화면과 경기 재생, 좁은 화면의 메뉴 이동을 확인했다.
구종 기대 효과는 선택 투수의 3,037구 중 2,757구에 모델을 적용했고 모델 미준비 표본은 0이었다.
경기 재생은 523개 frame을 검증한 후 실제 이동했고 RE24·카운트 가치·승리확률 패널을 펼쳤다.
2025 승리확률은 규정 미지원 안내를 표시했다. 확인한 화면의 alert와 준비 완료 후 브라우저 console
오류는 없었으며, 운영 API 로그에도 새 warning/error 또는 5xx가 없었다.

| HTTP 조회      | 5회 재조회 범위 |
| -------------- | --------------: |
| 구장 효과      |       577–649ms |
| 구종 기대 효과 |   1,071–1,178ms |

이 값은 운영 HTTP 왕복을 포함하며 5회 표본의 범위다. p95나 동시 사용자 부하 상한이 아니다.
매치업·투수 변화·데이터 품질은 최초 조회에 각각 7.77초·14.37초·13.71초가 걸렸다.
추가 재조회도 각각 8.41초·9.35초·14.70초로 느렸으므로 초기화에만 국한된 비용이 아니다.
이 경로의 조회 병목은 남은 개선 대상이다. 초기 목표인 선수 조회 1초를 모든 경로에서
달성했다고 판단하지 않는다.

원 실행 로그·모델 공개 해시·HTTP 검사·배포 전후 revision 목록은
`analysis/deployment/20260920T091626Z/`에 보존했다. 검증 결과와 별도로 생성한 운영 증거이며
백업 파일 또는 원장 파일을 대체하지 않는다. 배포 증거와 컨테이너 복구용 filesystem archive는
Git과 코드 lint/format 대상에서 제외한다.
