앞선 표본 대조에서 발견한 경기뿐 아니라 여섯 시즌의 공식 일정과 저장된 수집 목록을 전수 확인했다.

## 원인과 수정

- 2023-09-01 한화–LG, KIA–SSG, KT–키움, NC–삼성은 원문이 모두 보존돼 있었으나
  Naver 상태 코드 `4` 해석 실패로 `source_failure`에 남아 있었다. 코드만으로 종료를 정하지 않고
  summary의 명시적 종료 footer와 3아웃 증거를 함께 요구하도록 수정했다. 저장 원문 네 경기의
  hash를 검증하고 다시 정규화·전체 컴파일했으며, 모두 차단·경고 0과 공식 최종 점수 일치를 확인했다.
- KBO 기록정정 기본 동기화가 2020년부터 시작해 공식 조회 범위 검사에서 매번 실패했다.
  기본·예약 작업은 제도 도입 이후인 2022년부터 보유 시즌을 선택한다. 명시적 과거 시즌 요청이나
  원천 control 검증을 우회하지 않으며, 미지원 시즌을 공지 0건으로 저장하지 않는다.
- 공지의 줄바꿈과 닫는 괄호 뒤 쉼표 때문에 2022년 8건 모두에서 일부 통계가 누락됐다.
  명시적으로 열린 통계 그룹 안에서만 줄을 연결하고 불완전·모호한 경계는 거부한다.
  원문 45건은 모두 보존되며, 정상적으로 파싱되던 37건의 notice hash는 그대로다.
- 공식 집계만 정정 후 값인 경우에도 실제 compiler 기록이 다르면 완료로 평가하지 않는다.
  지원 통계의 공식값·계산값을 함께 검증하고, 적용할 batch가 없거나 근거가 부족하면 수동 검토로
  남긴다. 자책점은 기존대로 공식 원천값을 사용하고 compiler에서 계산하지 않는다.

공식 기록정정 공지는 2022년 8건, 2023년 8건, 2024년 10건, 2025년 19건으로 총 45건이다.
[KBO 제도 신설 발표](https://www.koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=8342)는
2022-04-29에 발표됐고 05-17 경기부터 적용됐다. 공지는
[KBO 기록정정현황](https://www.koreabaseball.com/Record/RecordCorrect/RecordCorrect.aspx)의
공식 control·목록 응답에서 취득했다. 2020–2021은 이 공지 서비스의 제공 범위 밖이다.

## 원천이 불완전한 올스타전

`99990716WEEA02022`는 격리를 유지한다. 현재 Naver 요약과 10회 응답도 저장 원문과
SHA-256이 같으며, 10회 시작·첫 타자 안내 두 행만 제공한다. 3–3 상태 이후 실제 투구·타석이 없다.
[KBO 공식 결과](https://www.koreabaseball.com/Schedule/Allstar/History/History2024.aspx)는
10회 승부치기 후 나눔 6–3 드림을 명시하지만,
[공식 문자중계](https://www.koreabaseball.com/Game/LiveTextView2.aspx?leagueId=1&seriesId=9&gameId=20220716WEEA0&gyear=2022)도
승부치기 결과 요약만 제공한다. 9회 종료로 바꾸거나 최종 점수에서 누락 플레이를 역산할 수 없다.
현 원장 계약에는 승부치기 배치 주자의 모델도 없어, 상세 근거와 규칙 지원이 함께 필요하다.

## 운영 반영 결과

누락 네 경기는 재수집 후 모두 차단·경고 0으로 검증돼 revision 1에 적재됐다.
2023년 공식 일정의 보존 원문 36개를 다시 hash 검증·파싱하고 기존 repository 경로로 분류를 재채택했다.
현재 정규시즌은 **모든 시즌 720경기, 합계 4,320경기**다. 시범 256경기·포스트시즌 86경기도
공식 분류의 누락이 없다. 운영 전체 DB는 4,693경기에서 4,697경기가 됐다.

공지 45건 중 **34건은 이미 반영**, 나머지 **11건은 새 revision 2로 반영**됐다.

김휘집·박수종·손호영의 판정 교정은 자동 제안의 충돌을 무시하지 않았다. 공지와 원장·주자 원문을 대조해
대상을 확인한 뒤 기존 `replace_event` 명령으로 판정만 수정했다. 전후 전체 컴파일에서

모든 15개 import job은 성공했고 후속 처리 대기도 없다. 작업본에는 불완전한 올스타전 한 경기만 남는다.

독립된 읽기 전용 DB 감사에서 45개 공지의 지원 통계 **177/177개**, 제공된 공식 필드
**130/130개**가 정정 후 값과 일치했다. 공식 선택 필드 미제공 47개는 0으로 채우지 않고 구분했다.
반영 전 4,693경기 중 예상한 11경기만 revision 1→2가 됐고, 신규 네 경기만 추가됐다.
나머지 **4,682경기의 revision·document hash는 동일**하며 삭제·예상 밖 변경은 없다.

앞선 손주영·임찬규·구자욱·송성문 표본의 KBO 시즌 기록도 다시 취득해 실제 분석 API와 대조했다.
22개 선수·시즌, **275/275개 항목이 일치**해 최초 조사에서 발견한 차이가 해소됐다.
이는 전 선수 시즌 합계의 전수 대조를 의미하지 않는다.
