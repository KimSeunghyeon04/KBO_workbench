# 기본 기록과 KBO 공개 기록의 표본 대조

이 문서는 반영 전 조사 기록이다. 같은 날 진행한 [전체 누락·기록정정 반영](2026-09-23-data-reconciliation.md)
후에는 동일 표본 275개 항목이 모두 일치했다. 아래 차이는 최초 발견 당시의 근거로 보존한다.

2026-09-23에 수집된 현재 sealed revision의 합계를 KBO 공식 공개 기록과 읽기 전용으로 대조했다.
화면 기능이나 자동 정정 기능이 아닌 별도 조사다. 외부 숫자로 DB·원장·통계를 덮어쓰지 않았다.

## 범위와 방법

대상은 2020–2025 확인된 정규시즌의 손주영·임찬규·구자욱·송성문이다. 공식 시즌 행이 존재하는
22개 선수·시즌을 비교했으며 전 선수에 대한 전수 검증은 아니다.

- [손주영 공식 통산 기록](https://www.koreabaseball.com/Record/Player/PitcherDetail/Total.aspx?playerId=67143): 2021–2025.
- [임찬규 공식 통산 기록](https://www.koreabaseball.com/Record/Player/PitcherDetail/Total.aspx?playerId=61101): 2020–2025.
- [구자욱 공식 통산 기록](https://www.koreabaseball.com/Record/Player/HitterDetail/Total.aspx?playerId=62404): 2020–2025.
- [송성문 공식 통산 기록](https://www.koreabaseball.com/Record/Player/HitterDetail/Total.aspx?playerId=65357): 2021–2025.

로컬 자료는 기존 `/api/v2/analysis/statistics/{batting|pitching}`에서 `competition=regular`,
기간 제한 없음, 최소 표본 제한 없음으로 읽었다. 모든 페이지를 읽고 페이지 사이 `sourceHash`가
같은지 확인했다. 비교 선수들은 해당 시즌에 팀별 행이 하나이며, 이적 선수의 팀별 비율을 평균하는
방식은 사용하지 않았다. 선수 ID와 이름 및 공식 페이지의 `KBO 정규시즌` 표를 확인했다.

투수는 G·TBF·IP·H·BB·HBP·SO·R·ER·ERA 10개, 타자는 G·PA·AB·R·H·2B·3B·HR·TB·BB·HBP·SO·
AVG·SLG·OBP 15개 항목을 비교했다. 이닝은 정수 아웃 수로 변환했다. 비율은 공식 표시 자릿수
(ERA 2자리, 타격 비율 3자리)로 반올림해 비교했고, ER은 모든 등판의 제공 여부를 확인했다.
현재 일반기록 API에 없는 W/L/SV/HLD·투수 HR·RBI·SB/CS는 비교 완료 항목에 넣지 않았다.

원본 HTML, API 응답, 취득 시각, SHA256, 항목별 비교 결과와 재현 스크립트는 로컬
`analysis/commit-preparation/20260923-basic-records/`에 보존했다. 핵심 파일은 `comparison.json`,
`compare-public-records.mjs`, `missing-games.txt`, `record-correction-2022.json`이다.

## 결과

총 275개 항목 중 254개 일치, 21개 불일치다. 22개 선수·시즌 중 19개는 비교 항목이 모두 일치했다.
불일치한 비율은 기초 건수 차이에서 파생되므로 독립적인 오류 21건이라는 뜻은 아니다.

실제 투구 2,496구는 로컬 값이며 이 공식 통산 표에는 NP가 없어 이번 비교 항목이 아니다.

## 차이 1: 2023년 9월 1일 경기 누락

공식 일정 분류 자료에는 매 시즌 정규시즌 720경기가 있지만, 현재 DB의 확인된 정규시즌은
2020·2021·2022·2024·2025가 각각 720경기, 2023만 716경기다. 2023년 미분류 1경기는 7월 15일
경기이며 이번 9월 1일 누락과는 별개다.

봉인된 공식 일정과 현재 적재 경기의 차집합은 다음 네 경기다. 공식 분류 행의 `game_id`가 없고
현재 정규시즌 분석 집합에도 없다.

| 날짜       | 공식 경기 ID  | 경기    |
| ---------- | ------------- | ------- |
| 2023-09-01 | 20230901HHLG0 | 한화–LG |
| 2023-09-01 | 20230901HTSK0 | KIA–SSG |
| 2023-09-01 | 20230901KTWO0 | KT–키움 |
| 2023-09-01 | 20230901NCSS0 | NC–삼성 |

[구자욱 일자별 기록](https://www.koreabaseball.com/Record/Player/HitterDetail/Daily.aspx?playerId=62404)과
[송성문 일자별 기록](https://www.koreabaseball.com/Record/Player/HitterDetail/Daily.aspx?playerId=65357)에서
연도를 **2023**, 종류를 **KBO 정규시즌**으로 선택해 09.01 행을 확인했다. 기본 페이지의 현재 연도
기록을 과거 기록으로 간주하지 않았다.

| 선수   | 누락 경기의 공식 기록                 | 시즌 합계 차이 (로컬 → 공식)                                      |
| ------ | ------------------------------------- | ----------------------------------------------------------------- |
| 구자욱 | PA 3, AB 3, H 0, R 0, SO 2            | G 118→119, PA 512→515, AB 450→453, SO 79→81                       |
| 송성문 | PA 4, AB 4, H 2, R 2, SO 0, 장타 없음 | G 103→104, PA 434→438, AB 384→388, H 100→102, R 41→43, TB 137→139 |

각 선수의 차이는 해당 한 경기의 기록과 정확히 일치한다. 구자욱의 AVG/SLG/OBP는
0.338/0.498/0.410 대 0.336/0.494/0.407, 송성문은 0.260/0.357/0.323 대
0.263/0.358/0.325이며 분자·분모 누락으로 설명된다. 이 조사만으로 파일 워크스페이스에서 해당
경기가 어느 처리 단계에 남아 있는지까지 판정하지 않았다.

## 차이 2: 구자욱 2022년 사후 기록정정 미반영

구자욱 2022년은 G 99·PA 442·AB 409 등은 일치하지만 H는 로컬 119 대 공식 120,
TB는 163 대 164다. AVG/SLG/OBP도 0.291/0.399/0.338 대 0.293/0.401/0.340이다.

읽기 전용으로 99개 선수·경기 fact와 보존 Naver 공식 타격선을 대조했을 때 경기별 H가 모두
일치했고 두 합계도 119였다. 집계 SQL이 저장된 안타를 누락한 경우가 아니다.

[KBO 기록정정 현황](https://www.koreabaseball.com/Record/RecordCorrect/RecordCorrect.aspx)의
2022 정규시즌 5번 공지(`2022:0:5`, 정정일 08/05)는 **7월 30일 롯데–삼성 6회말 구자욱의
실책 출루를 안타로 정정**한다. 구자욱 안타 2→3·루타 5→6·타점 0→1, 이학주 실책 1→0,
김유영 피안타 0→1, 박세웅 자책점 3→5가 연결된 정정이다.

현재 `20220730LTSS02022` revision 1의 event sequence 390,
`20220730LTSS02022:relay_006:1:5`는 `reached_on_error`다. 해당 경기의 구자욱 fact는 H 2·
2B 1·3B 1·HR 0이므로 공지의 안타 1개를 반영하지 않은 상태가 시즌 차이를 정확히 설명한다.
보존 boxscore는 일부 항목만 사후 갱신되어 있어, 최신이라고 가정해 모든 값을 한꺼번에 덮어쓸 수 없다.

추가로 현재 공식정정 파서는 괄호 내부의 줄바꿈과 닫는 괄호 뒤 쉼표가 있는 선수별 문장을 일부
typed 변경값으로 추출하지 못한다. 원문은 보존되지만 이 공지에서는 박세웅 ER만 추출되므로,
정정 검토를 진행하기 전 해당 파서를 비식별 fixture 회귀 테스트와 함께 보완할 필요가 있다.
현재 DB에는 이 공지도 적재되어 있지 않다. 이번 조사에서는 파서나 운영 기록을 변경하지 않았다.

## 후속 데이터 점검 순서

1. 2023-09-01 네 경기의 수집·검증·적재 이력을 확인하고 누락 단계를 처리한 뒤 정규시즌 720경기와
   두 타자 시즌 합계를 재검증한다.
2. 공식정정의 줄바꿈·쉼표 파싱을 보완한 다음, 2022-07-30 경기를 기존 structured correction 경로로
   검토한다. 관련 타자·야수·투수 변경과 전체 컴파일을 함께 확인하고 새 revision으로 적재한다.
3. 이 표본 결과를 리그 전체 무오류 판정으로 확대하지 않는다. 이후 전수 대조 시 동일 선수 identity·
   경기 집합·기록정정 시점·공식 분모를 먼저 맞춘다.
