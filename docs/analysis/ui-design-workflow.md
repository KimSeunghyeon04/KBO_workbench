# 분석 UI 설계 도구와 작업 기준

설정일: 2026-09-24. 이 문서는 개발 도구의 역할과 사용 순서를 정한다. 앱의 통계·좌표·데이터
계약은 [전체 설계](design.md)와 각 기능 문서가 소유한다.

## 기본 작업 흐름

분석 UI를 작업할 때 `kbo-analysis-ui` 스킬로 선수 중심 탐색과 해석 기준을 확인한다.
Graft로 소유 모듈을 찾고 실제 화면을 브라우저에서 본 다음, 아래에서 필요한 도구를 선택한다.
모든 디자인 스킬을 매번 일괄 실행하지 않는다.

- **Impeccable**: 기존 화면의 정보 위계·배치·문구·복잡도를 개선한다. `critique`, `distill`,
  `layout`, `clarify` 등 작업 목적에 맞는 모드를 사용한다.
- **frontend-design**: 새 화면 또는 명시적인 재설계에서 시각적 방향을 잡는다. Impeccable과
  같은 화면을 반복 재설계하지 않고 하나의 방향을 유지한다.
- **web-design-guidelines**: 접근성·상호작용 검토가 필요할 때 최신 원문을 읽고 적용한다.
- **브라우저**: 실제 데이터가 표시되는 화면에서 탐색·조건 변경·비교·근거 이동을 확인한다.
- **Context7**: 사용할 라이브러리의 현재 API와 설정을 확인한다.
- **Graft**: 코드의 소유 모듈과 호출 관계를 확인한다. 저장소의 기존 그래프 범위를 유지한다.
- **Figma**: 연결된 계정과 디자인 작업 범위가 있을 때 시안을 비교하거나 확정된 시안을 구현한다.
- **shadcn MCP**: 필요한 UI 부품을 검색하고 기존 컴포넌트와 비교한다. 실제 채택은 현재
  스타일과 의존성에 맞춰 수행한다.

## KBO 분석 화면의 판단 기준

선수와 조회 범위, 핵심 관측, 비교·변화, 상세 근거 순으로 이해할 수 있게 한다. 구질 차이는
산점도, 코스는 히트맵, 기간별 변화는 추세선처럼 질문에 맞는 표현을 고른다. 정확한 값의
검색·정렬에는 표를 사용하며 모든 분석을 표로 설명하려 하지 않는다.

수치에는 단위·분모·비교 기준을 표시한다. 미제공과 0, 관측과 예측, 작은 표본과 통계적 확실성을
구별한다. 기존 서버 응답을 표현하고 UI에서 새로운 통계·야구 규칙을 만들지 않는다.
선수·시즌·경기 종류·기간은 분석 항목 이동에서 유지한다. 숨겨진 비교·상세 화면을 위해
추가 시즌이나 원시 투구 전체를 미리 조회하지 않는다.

선수 리포트 상단에 전체 선수 검색과 해당 선수의 기록 시즌을 바로 노출한다. 이름이나 ID로
찾을 수 있고 결과에는 이름, 출생연도, 주 포지션과 구단 이력을 표시한다. 고른 시즌의 타석·투구
기록에 맞는 분석 탭을 표시하고, 전환 후에도 해당 기록이 있으면 보고 있던 탭을 유지한다.
해당 기록이 없으면 기본 기록을 연다. 기본 기록은 시즌 합계를 최신순으로 표시하고 날짜를 지정한 경우
선택 시즌의 해당 기간을 보여 준다. 다섯 탭의 공통 경기 종류·기간은 선수 머리글의 시즌 옆에서 바꾼다.
접힌 상태에서 적용 범위를 읽을 수 있고 펼치기 자체는 추가 조회를 만들지 않는다.
투구 조건은 구종·코스 화면에, 상대 선택은 맞대결에 둔다. 경기별에서 등판 변화·부담 링크를
표 위에 표시하고 경기 날짜에서 봉인된 경기 재생을 연다. 상황별 표에서 원하는 행의
카운트별 성적을 고른다. 구종별 표의
구종을 선택하면 같은 구종으로 지도와 반응을 조회한다. 배합·궤적은 이 구종을 두 번째 공에 적용한다.
맞대결은 직접 성적을 먼저 보여 주고 유사 조건의 분석은 펼쳤을 때 조회한다.
리그 성적도 시즌·성적 종류·경기 종류를 먼저 선택하고 기간·집계·최소 표본·정렬은 `세부 조건`에서
조정한다. 활성 세부값은 접힌 요약에 남기며 조회·URL은 실제 조건 변경 시에만 갱신한다.

GET 조회 오류는 원래 오류 메시지와 명시적인 재시도로 복구하며 실패한 조회만 다시 보낸다.
조회 중이거나 입력 조건이 유효하지 않으면 재시도를 막고 선수·URL 조건을 유지한다. 오류 복구를
위해 교정·적재·모델 실행 같은 mutation 명령을 자동 재전송하지 않는다.

세부 적용 기준은 설치된 `kbo-analysis-ui/SKILL.md`에 있다. 이 스킬은 KBO Workbench 분석
화면의 설계·개선·검토에 자동 선택될 수 있으며, 백엔드 전용 변경에는 적용하지 않는다.

## 설치 위치와 버전

현재 사용자 환경의 `~/.codex/skills/`에 다음 스킬을 설치했다. 저장소를 복제하는 것만으로
다른 개발자 환경에 설치되지는 않는다. 상위 저장소의 설치 파일은 수정하지 않았다.

- [Impeccable](https://github.com/pbakaus/impeccable): `.agents/skills/impeccable`,
  커밋 `e0881d2de397d5e9761d7b35ff5017d8f5ebf69b`, 스킬 4.3.1 / 엔진 0.1.5.
- [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design):
  커밋 `34040c9c568585f6929bedeaad110ad08f079624`.
- [web-design-guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines):
  커밋 `063bee94c3f4df8453406c830b0a7df0f2860278`.
- `kbo-analysis-ui`: 이 프로젝트의 선수 중심 분석·시각화·검증 기준을 담은 사용자 스킬.

shadcn MCP는 사용자 `~/.codex/config.toml`에 다음 설정으로 등록했다. 기존 Context7·Graft
등의 설정은 보존한다. Windows에서는 `npx.cmd`로 실행한다.

```toml
[mcp_servers.shadcn]
command = "npx.cmd"
args = ["-y", "shadcn@4.21.0", "mcp"]
```

공식 기본 레지스트리 검색은 `components.json` 없이 사용할 수 있다. 컴포넌트를 앱에 실제로
도입할 때 필요한 설정을 해당 기능 변경과 함께 추가한다. 이번 설정은 앱 초기화, Tailwind
전환, 컴포넌트 일괄 교체 또는 운영 배포를 수행하지 않는다.

Figma는 2026-09-25 플러그인 설치와 인증된 계정 조회 응답을 확인했다. Figma 도구와 관련
스킬이 사용 가능하다. 제공된 디자인 URL이나 사용자가 요청한 시안 작업에 적용하며, 개별
파일의 읽기·편집 권한은 해당 파일을 사용할 때 확인한다.

## 확인한 동작과 사용 예

- Impeccable Windows 엔진의 체크섬 검증과 `engine-probe` 응답을 확인했다.
- shadcn MCP의 초기 연결, 7개 도구 목록, 공식 레지스트리의 `combobox` 검색을 확인했다.
- Context7 문서 조회와 Graft 그래프 조회·재생성이 동작한다.
- 브라우저 도구의 연결 상태 조회를 확인했다.
- Figma의 인증된 계정 조회를 확인했다. 이번 설정 확인에서 Figma 파일을 생성·수정하지 않았다.
- 스킬 4개는 공식 스킬 검증기를 통과했다. Codex TOML 설정과 기존 MCP 항목 보존, 변경 문서의
  Prettier 형식, `git diff --check`도 확인했다. 애플리케이션 코드·의존성 변경은 없다.

설치한 스킬 4개는 현재 세션의 사용 가능 목록에서 확인했다. 새 MCP가 도구 목록에 나타나지 않으면 Codex의 MCP 설정에서
서버를 다시 시작한다. 사용 예:

```text
$kbo-analysis-ui 코스·결정구 화면을 실제 브라우저로 보고 핵심 분석이 먼저 읽히게 개선해 줘.
$impeccable critique 선수 리포트의 정보 위계와 복잡도를 검토해 줘.
$frontend-design 선수 분석 홈의 새 레이아웃을 설계해 줘.
$web-design-guidelines 변경한 분석 화면의 접근성과 상호작용을 검토해 줘.
shadcn MCP에서 선수 검색에 적합한 combobox 예제를 찾아 기존 선택기와 비교해 줘.
```

설치·설정 검증은 UI 개선 효과의 검증과 별개다. 화면을 변경할 때는 관련 테스트와 실제
데스크톱·모바일 브라우저 흐름으로 결과를 확인한다.
