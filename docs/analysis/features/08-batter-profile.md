# A08. 타자 약점과 강점 지도

전체·구종·구속대·코스 반응과 종결 PA 성적의 [A/B 기간 비교](../period-comparison.md)를 제공한다.
반응과 종결 구종 성적의 grain·분모를 유지한다.

선행 조건: A04의 코스 집계·A07의 선구안 표본. 타구속도·발사각 기반 평가를 포함하지 않는다.

## 첫 화면

선택 타자의 구종·구속대·코스별 스윙/컨택/헛스윙 지도와 인플레이 결과를 제공한다.
상단의 **코스·반응 / 카운트별 대응 / 종결 성적 / 기간 비교 / 표본 기준** 탭에서 분석을 전환한다.
종결 성적에는 타석 결과를, 코스·반응에는 투구별 반응을 표시한다. 기간 비교 탭에서 A/B 조건을
바로 편집하며, 탭 전환은 선수·시즌·기간·상황 필터를 유지한다.

## 카운트별 대응

**전체**는 선택 타자가 모든 상대 투수에게서 받은 실제 투구를 하나의 트리에 표시한다.
**좌완·우완 비교**는 확인된 투구 손에 따라 트리 두 장을 나란히 표시한다. 같은 경기·봉인된 revision의
원문 해시와 투수 ID가 일치하는 Naver 프로필 선언에서 투구 손을 읽는다. Naver에 투구 손 표기가
없으면 경기·원문 해시·투수 ID와 이름이 일치하는 검토된 KBO 공식 프로필을 사용한다. 근거가 없거나
Naver 표기가 충돌하는 투구는 전체에 집계하고 미확인 수를 표시한다. 조회 범위에 확인 투구가 없으면
비교 화면에서 그 상태를 알린다.
카운트 원은 받은
구종의 비중을 보여준다. 원 가운데는 해당 카운트의 전체 구종을 선택하고, 바깥 조각을 고르면
양쪽 트리의 모든 카운트 화살표가 그 구종을 받았을 때의 전이율을 표시한다.
상세의 스윙률은 선택 카운트·구종의 실제 투구 중 스윙한 비율이다. 집계에는 위치나 구종이
확인되지 않은 투구도 포함한다. “같은 조건으로 코스 보기”는 동일한 선수·시즌·날짜·경기 종류·
표본에 선택 카운트와 구종을 적용한다. 좌우 비교에서 코스 지도를 열면 해당 투수의 투구 손 조건도
전달한다. 코스 지도에는 위치·존이 확인된 투구를 표시한다.

`GET /api/v2/analysis/batter-profile/:batterId/count-flow`는 이 탭에서 조회한다. A04와
같은 실제 투구·종결 연결 규칙을 사용하며, 카운트와 구종별 스윙 수 및 스윙률을 함께 제공한다.
`split=pitcher-hand`는 `byPitcherHand`에 좌완·우완 집계와 미확인 투구 수를 제공한다.
코스 및 A/B 타자 응답의 `pitcherHand=L|R`은 상대 투수의 투구 손을 적용한다. 타석 결과에서는
종결 투수, 종결 투구가 없으면 기록된 투수의 투구 손을 사용한다.
코스 조회에서 `pitchType=`은 구종 미상을 선택하며, 생략하면 모든 구종이 대상이다.

검토한 KBO 공식 근거는 `pnpm maintenance:import-official-pitcher-hand --profile <JSON>`으로
등록한다. `--dry-run`을 붙이면 현재 봉인 기록과 대조해 일치하는 실제 투구 수를 확인할 수 있다.
[등록 파일 예시](../../../database/reference/pitcher-hand-20220315HTSS02022-64464.json)는
KBO 선수 페이지와 확인일, 페이지의 투타 표기, 적용할 경기와 원문 해시를 담는다.

## 지표와 귀속

| 표             | 단위와 분모                                                                      |
| -------------- | -------------------------------------------------------------------------------- |
| 반응 지도      | 실제 투구; Swing%=스윙/공, Whiff%=헛스윙/스윙, Contact%=(스윙−헛스윙)/스윙       |
| 인플레이 결과  | 완료 결과에 연결되는 terminal in-play 투구; 안타·장타·홈런/해당 인플레이 결과 수 |
| 종결 구종 성적 | 한 완료 PA의 종결 투구에만 연결; AB·H·TB를 함께 표시하고 종결 구종 기준임을 명시 |

볼넷·사구·삼진을 그 타석의 모든 구종 성과로 복제하지 않는다. 종결 투구가 없거나 자동 판정으로
끝난 PA는 미귀속 그룹에 보존한다. 결과 표의 합계는 공식 PA/AB 범위와 대조한다.
컨택은 파울을 포함한 관측 스윙 결과이며 타구 질을 뜻하지 않는다.

구종·구속·코스부터 시작한다. A03의 보정 무브먼트 구간을 추가할 때에도 원 중계 구종 기준을 유지하고
투수별 GMM 번호를 리그 공통 구종으로 합치지 않는다. 선택 공의 기하량만 안정적으로 연결한다.
비교군은 같은 카운트·구종·구속대·타석 좌우·코스의 다른 타자이며 A07의 최소 표본 규칙을 재사용한다.
표본 부족 구간은 빈색/미비교로 표시하고 순위를 지어내지 않는다.

## 구현 순서

1. [x] `contracts/pitch-outcomes.ts`에서 pitch 반응과 PA 결과 배열을 다른 타입으로 정의.
2. [x] `persistence/batter-profile-repository.ts`에 각 grain별 쿼리와 terminal 연결 구현.
3. [x] A04/A07과 같은 분류·비율을 공유하되 결과 귀속은 공유 grain 모듈 `game-core/pitch-outcomes.ts`에 구체적으로 작성.
4. [x] `/api/v2/analysis/batter-profile/:batterId`, 기존 선구안과 연결되는 타자 프로필 화면 추가.
5. [x] cell 선택 시 해당 투구 또는 PA 목록을 각각 제공하고 같은 revision 재생으로 연결.

## 검증과 완료 조건

한 PA에 직구 3개·변화구 2개 후 안타가 있는 fixture에서 반응은 5투구, 결과는 1PA가 되어야 한다.
자동 볼넷·무투구 고의사구·타석 중 대타·partial PA·tracking 없는 종결구를 검증한다.
원 구종 미상, 희소 cell, 무스윙 cell의 null을 확인하고 반응 표와 결과 표의 분모를 화면에서 구분하면 완료한다.
