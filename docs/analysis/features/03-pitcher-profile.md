# A03. 투수 구질 프로필

선행 조건: A01. 기존 투구 움직임 화면을 확장하는 기능이며 새 구질 계산기를 만들지 않는다.

## 제공할 결과

2020–2025의 실제 수집 시즌을 선택하고 투수별 구종 구성, 구속, 보정된 상대 위치·도착 시간,
분산, 시즌 포심 분포 안팎, 헛스윙/스윙을 비교한다. 원 중계 구종과 GMM 군집을 계속 구분한다.
군집 번호를 다른 투수·기간의 동일 구종으로 취급하지 않는다.

첫 범위는 현행 지표와 기간 요약이다. 실측 RPM·릴리스·익스텐션은 추가하지 않는다.
원천 궤적 유도 VAA/HAA는 별도 패널에서 공통 중간면의 각도로 제공한다.

## 계산·표본

- 기존 `alignPitchTrajectory`, `comparePitchTrajectory`, 평균 포심 및 구장 보정 정책을 재사용한다.
- 구종 사용률은 대상 투수의 전체 실제 투구가 분모다. 미상 구종도 별도 행에 포함한다.
  구속 평균은 유효 구속 표본, 구질 평균은 유효 궤적 표본을 따로 표시한다.
- 날짜 필터는 대상 투구를 좁힌다. 기준은 명시한 같은 시즌·경기 종류 집합으로 유지한다.
  display 필터와 대상/기준 변경을 분리하고 기준 수·기간을 응답에 포함한다.
- 구장 보정이 되는 표본과 부족/미지원 표본을 구분한다. 선택한 두 기간의 보정 coverage가 달라지면
  보정 완료 표본끼리의 비교를 별도 표시하고 전체 차이를 한 숫자로 확정하지 않는다.
- 서로 다른 시즌의 상대 좌표는 각 시즌 포심 기준의 차이를 포함한다. 절대 구속과 같은 기준의
  기하량을 함께 보여주고 시즌 상대 좌표 차이를 절대 무브먼트 변화로 표기하지 않는다.

## 구현 위치와 순서

1. [x] 기존 `contracts/pitch-analysis.ts`에 명시적 scope·대상/기준 표본·기간 요약 계약 추가.
2. [x] 기존 `persistence/pitch-analysis-repository.ts`의 catalog·reference·calibration·sample 입력에
       같은 경기 분류를 적용. 관련 키에 scope와 분류 dataset hash를 추가.
3. [x] `server/pitch-analysis-service.ts`는 기존 군집 계산과 결과 조립 유지. 새 기간 요약은 작은 순수 함수로 구현.
4. [x] 기존 `web/pages/pitch-analysis-page.tsx`, `analysis/pitch-presentation.ts`에서 시즌 목록·기간·표본 표시 확장.
5. [x] 원천 궤적 평가 함수 `pitchApproachAngles`와 진입각 패널을 추가하고 기존 보정 좌표와 분리.

API 경로는 기존 `/api/v2/analysis/pitch-shape` 및 `/:pitcherId`를 유지한다.
이 기능의 표본을 매번 6개 시즌 전체 적재하지 않는다. 시즌 기준 cache와 대상 투수 조회를 유지한다.

## 검증과 완료 조건

기존 trajectory/calibration/clustering/service/API/UI 테스트를 확장한다. 2020–2023 원천 면,
2024–2025 혼합 면, 첫 시즌·적은 경기·지원하지 않는 구장·구종 미상·빈 기간을 포함한다.
표시 필터로 기준이 변하지 않고 같은 scope/hash의 기존 점 좌표가 유지되는지 회귀 검증한다.
scope 변경 시 평균 포심과 대상 투구가 같은 보정 정책을 쓰며 cache가 정확히 무효화되면 완료한다.

## 원천 궤적 진입각

`/api/v2/analysis/pitch-angles/:pitcherId`는 완료 경기의 대상 투수만 읽는다. 공통 중간면
`y=17/24 ft`를 통과하는 시각 t에서 원천 속도 `v=v0+a×t`를 계산한다.
`VAA=atan2(vz,-vy)`, `HAA=atan2(vx,-vy)`를 도 단위로 제공한다. VAA 음수는 하강,
HAA 양수는 원천 +x 방향이다. 투수 손을 추정해 부호를 뒤집지 않는다.

이는 포심 대비 상대 좌표나 구장 보정 각도가 아니다. 원천 cross_plate_y가 앞면/중간면으로
바뀌어도 같은 면에서 계산한다. [Trackman 공식 정의](https://support.trackmanbaseball.com/hc/en-us/articles/5089413493787-Radar-Glossary-Of-V3-Terms)는
홈플레이트 앞면 기준이므로 이 중간면 수치와 직접 동일시하지 않는다.

구종별·경기별 평균과 표준편차, 통과 높이·가로 위치, 포함/제외 표본과 근거 투구를 제공한다.
대칭·직선 궤적·독립 유한차분 검증, 혼합 원천 면의 불변성, 실제 6시즌 표본을 확인했다.
독립 장비의 실측 진입각과 비교한 정확도 검증은 아니며 코스 구성과 원천 측정 편향이 남는다.
