# A11. 득점과 승리 기여

선행 조건: A01·A02. RE24, 카운트 기대득점, 승리확률을 각각 독립 배포한다.
이 기능은 typed 경기 상태를 소비하며 compiler의 상태 전이·주자 이동을 다시 계산하지 않는다.

2026-09-21부터 RE24·카운트는 2023–2025 적용 시즌을 지원한다. 승리확률은 지원 규정의
선행 학습과 두 검증 시즌이 확보된 2025만 관리·공개한다. [기간 정책](../model-management.md)을 따른다.

## 1단계: RE24와 플레이 가치

주자 8상태 × 아웃 3상태의 남은 기대득점 표를 만든다. 첫 훈련은 확인된 정규 9이닝 경기의
1–8회 중 3아웃까지 완전히 관측된 반이닝으로 제한한다. walk-off가 가능한 마지막 이닝을
무조건 3아웃 완료 표본만 골라 섞는 선택 편향을 피하고 적용 범위를 명시한다.
단축·중단·source boundary가 불완전한 반이닝은 제외한다. 9회 이후 적용은 초기에는 참고값으로 구분한다.

훈련 표본은 타석 시작 상태를 PA당 한 번 읽고 그 시점부터 해당 반이닝 종료까지 실제 득점을
label로 연결한다. 무투구 타석도 포함한다. PA 내부 투구 수만큼 같은 상태를 반복 가중하지 않는다.
상태별 평균·표본 수를 저장하고, 작은 상태는 과거 학습 기간의 동일 상태로 묶은 단순 기준을
validation에서 비교한다. 관측 없는 상태를 0으로 채우지 않고 모델 미지원으로 표시한다.

```text
공격팀의 플레이 득점가치 = 해당 플레이 실제 득점 + RE(after) − RE(before)
투수팀 관점의 같은 플레이 가치 = 위 값의 음수
```

applied atomic play의 before/after를 사용하고 실제 득점은 해당 공격팀 score delta를 읽는다.
3아웃 종료의 RE는 0이다. walk-off·중도 종료의 남은 상태를 임의로 0으로 만들지 않으며 첫
완료이닝 가치 집계에서는 제외한다. 상태 미지원 시 해당 가치와 전체 합계는 incomplete 상태로 표시한다.
한 플레이의 값을 타자·주자·수비수 모두의 개인 공로로 중복 배분하지 않는다.

## 2단계: 카운트와 투구 득점가치

주자·아웃·투구 전 볼/스트라이크의 기대득점을 별도로 학습한다. 실제 관측된 각 결정 시점 한 번을
표본으로 하고, 종결 카운트 4볼/3스트라이크를 일반 상태로 학습하지 않는다. 희소 상태는 RE24로
축소하는 명시적 계산을 과거 validation에서 평가하고 적용 강도를 고정한다.

terminal pitch와 plate_result가 분리되어 있을 때에는 compiler의 연결을 이용해 투구 시작부터
그 atomic 결과 이후까지를 하나의 **분석용 가치 전이**로 묶는다. 원장·play fact를 변경하는 새
경기 전이가 아니다. 명확히 묶을 수 없는 경우 unsupported로 남긴다.
독립 도루·폭투·자동 판정·무투구 결과는 별도의 비투구 전이로 유지한다.

가치 전이는 적용된 원래 상태 변화들을 정확히 한 번만 덮어야 한다. 투구와 비투구 값을 모두
합해야 반이닝 총 득점 변화와 일치하며, 투구에 연결된 plate_result를 다시 더하지 않는다.
견제사로 끝난 partial PA, 타석 중 교체, 투구에 수반된 주자 이동도 이 원칙으로 테스트한다.
모든 투구에 타석 최종 득점가치를 나누거나 복사하지 않는다.

## 3단계: 승리확률

정상 종료 경기를 대상으로 이닝·초말·점수차·주자·아웃·예정 이닝 수에서 홈 승/무/패의 확률을
예측한다. 초기에는 9이닝 정규시즌·지원하는 연장 범위로 제한하고 불명확한 경기 운영 조건,
몰수·중단·미완료 경기는 제외한다. 원래 규정과 적용 규정을 구분하고, 확인된 종료 상태가 있을 때만
더 짧은 연장 상한으로 학습 입력을 재구성한다. 관측하지 않은 추가 이닝은 만들지 않는다.

빈도가 충분한 거친 상태표를 기준으로 두고 정규화한 다항 로지스틱 모형을 비교한다.
game 단위 시간 분할로 multiclass log loss/Brier와 확률 보정을 평가한다. 동일 경기의 많은
상태가 label을 반복하므로 학습 가중과 보고 지표에서 경기당 기여를 명시하고 경기 bootstrap을 쓴다.

승리확률 곡선은 P(home win)를 표시한다. 무승부를 포함한 가치 합계는
`W = P(home win) + 0.5 × P(draw)`의 변화로 별도 정의하고 ‘무승부 0.5 기준 WPA’라고 표시한다.
종료 상태는 승 1·무 0.5·패 0이며 홈/원정 변화는 부호가 반대다. P(win)과 W를 같은 값으로 표시하지 않는다.
끝내기는 승리 모형의 정상 terminal이고 RE24의 미완료 이닝 처리와 분리한다.

## 검증과 완료 조건

- 작은 반이닝에서 총 가치 = 실제 총 득점 − 시작 RE가 되는 망원합을 검증한다.
- 만루 볼넷·홈런·병살·득점 취소·독립 도루·끝내기·콜드·partial PA·자동 볼넷·책임 투수 교체를 포함한다.
- 값을 합산할 때 terminal pitch/plate_result/runner movement가 중복되지 않아야 한다.
- 평가 시 미래 label을 전처리에 사용하지 않고 미래 시즌 상태 빈도로 희소 상태를 보완하지 않는다.
- RE는 validation MAE/RMSE와 상태별 편향으로 단순 표 대비 평가한다. WPA 모델은 validation 두
  연도의 log loss 개선·확률 보정과 마지막 고정 평가를 보고하고, 개선 없으면 단순 기준을 유지한다.
- 각 단계의 표본·제외·가치 부호·미지원 상태와 근거 play가 일치하면 해당 단계 완료다.

## 구현한 실행 계약 (2026-09-20)

- `pnpm analysis:train-run-expectancy --through 2024 --dry-run`은 RE24,
  `analysis:train-count-expectancy`는 카운트 RE, `analysis:train-win-probability`는 승리확률을
  독립 학습한다. `--dry-run`을 빼면 writer lock 아래 완전한 모델 파일을 저장한 뒤 포인터를
  마지막에 공개한다. API/화면에서는 학습하지 않는다. 실행 중인 서버가 writer lock을 점유하면
  먼저 서버를 정상 종료해야 한다. 모델별 디렉터리는 독립적이다.
- RE24 후보는 과거 전체 상태 평균과 최근 연도 평균을 과거 전체 평균으로 20/100표본 축소한
  표다. 두 검증 연도 모두 RMSE 개선, 합산 경기 bootstrap MSE 차이 95% 상한 < 0일 때만
  복잡한 표를 채택한다. 상태별 표본·편향, MAE/RMSE를 저장한다.
- 카운트 표의 288상태는 관측 결정 시점으로 학습하고, RE24로 100표본 축소한 기준과 20표본
  후보를 비교한다. RE24 기준도 각 학습 종료일까지의 PA로만 만든다. 4볼·3스트라이크는
  일반 상태가 아니다. 연결된 종결 투구와 결과 사이의 상태 불변 review/administrative만
  허용하며 교체·독립 주자 이동을 건너뛰지 않는다. 불명확하면 미지원이다.
- 학습 입력은 32경기씩 읽고 모델에 필요한 관측만 남긴다. 학습 시 불필요한 movement 조회를
  생략하고, CPU 적합 전에 DB 연결을 반환한다. 전용 CLI의 worker 1개/대기 1개, 5,000관측
  전송 단위와 30분 실행 제한을 사용한다. 취소·시간 초과 시 worker를 종료하고 포인터를
  공개하지 않는다. 일반 서버 worker의 기존 60초 제한은 유지한다.
- 원천 manifest는 current revision 및 경기 분류 해시를 포함한다. 조회할 때 같은 snapshot의
  원천과 비교한다. 변경되면 이전 파일을 그대로 적용하지 않는다. 평가 연도는 훈련 다음
  시즌으로 한정하고, 요청 season과 실제 경기 season의 불일치를 거부한다.
- 승리확률은 경기마다 고유한 count 비의존 상태를 수집하고 경기별 가중치 합계를 1로 한다.
  훈련 경기 최소 30개, 승/무/패 세 결과의 관측이 필요하다. 상태표는 연장 상한·3이닝 구간·
  초말·아웃·주자 유무·[-4,4] 점수차와 리그 사전분포 2경기 상당의 축소를 사용한다.
  후보는 표준화한 이닝/남은 이닝/초말/아웃/각 베이스/점수차 및 명시적 상호작용 13개 특성의
  3분류 로지스틱이다. 점수차는 [-20,20], λ는 0.1/1/10, 가중 평균 음의 로그우도 +
  λ/2 × 절편 제외 계수 제곱합으로 고정한다. 최대 500회, 수렴 실패는 미채택이다.
  두 검증 연도 log loss 개선과 경기 bootstrap 95% 상한 < 0을 요구한다. multiclass Brier와
  결과별 10구간 보정표도 저장한다. bootstrap은 seed 73129, 1,200회다.
- 승리 모델의 첫 규정 범위는 확인 가능한 2022–2024년 정규시즌 12회 상한이다.
  [2022 KBO 공식 안내](https://www.koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=8309)와
  [2025 KBO 공식 안내](https://www.koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=11496)를
  근거로 2025년은 11회로 구분한다. 2020·2021년 특례는 지원하지 않는다.
- 승리 모델은 적용 연도(`through + 1`)의 연장 상한 하나로 학습·선택·평가한다. 2025 적용 모델은
  2022–2024 정상 종료 경기를 11회 기준으로 재구성한다. 9–11회 종료 결과는 유지하며 12회에
  진입한 경기는 실제 관측된 11회말 3아웃 동점에서 학습용 무승부로 종료한다. 그 뒤 상태와 원래
  최종 승패는 사용하지 않는다. 11회 종료 증거 누락·모순·콜드·몰수는 제외한다. 원장·DB fact는
  변경하지 않는다. 상태 중복 제거와 경기 가중치는 잘라낸 뒤 다시 계산한다.
- 학습 정책은 `regular-2022-2025-shortened-limit-v1`이다. 이전 정책 파일은 새 모델로 간주하지
  않고 재학습한다. 2023/2024 후보 비교도 같은 11회 기준을 사용하고 2025는 선택 후 평가한다.
  당시 12회를 고려한 선수 운용 차이가 남을 수 있음을 화면에 설명한다. 실제 2025 검증에서
  710경기·57,431상태를 지원했고, 다항 로지스틱(λ=0.1)의 log loss 0.5862/Brier 0.3554를 기록했다.
- 재생의 세 패널은 열 때만 조회한다. 원래 atomic play를 바꾸지 않으며 정확한 revision과
  document hash를 검증한다. RE24에는 순수 단일 주자 도루/실패, 명시된 번트, 복합 플레이
  분류를 붙인다(A13b). 전체 플레이 가치를 개별 주자에게 배분하지 않는다.
