# A09. 투타 매치업

선행 조건: A03·A08. 확률 예측은 A10이 검증 기준을 통과한 뒤에만 추가한다.

2026-09-21부터 2023–2025 적용 시즌별로 A10 기반 모델과 타자 효과를 별도 검증한다.
아래 2023/2024 검증·2025 평가 설명은 2025 모델의 예시다. [기간 정책](../model-management.md)을 따른다.

## 첫 범위: 기술 통계

선택 투수와 타자의 직접 상대 투구·타석 수 및 결과를 보여주고, 그 투수와 구질이 비슷한 공에 대한
해당 타자의 반응을 별도로 보여준다. 직접 맞대결이 없다고 빈 분석 화면만 제공하지 않되,
유사 표본을 직접 상대 전적으로 합산하지 않는다.

## 유사 표본 정의

- 최초 구현은 같은 원 구종·카운트·타석 좌우와 동일한 구속 구간을 기준으로 한다.
  A03의 같은 시즌·기준에서 계산한 구질 거리로 추가 좁힐 수 있다.
- 거리의 표준화는 기준 리그 표본에서 적합한다. 서로 다른 시즌 상대좌표를 그대로 한 공간에 놓지 않는다.
- 개별 투수의 clusterId를 리그 공통 분류로 쓰지 않는다. 투수 좌우를 stance에서 추측하지 않는다.
- 구속/구질 범위와 최소 표본은 validation에서 정한 한 설정으로 고정한다. 선택 선수의 좋은 결과가
  나올 때까지 구간을 확대하는 자동 fallback은 없다. 조건을 바꾸면 사용자에게 그대로 표시한다.
- 첫 화면에서 무브먼트 거리의 예측 효과를 검증하기 전에는 단순 필터 기반 유사 표본이라고 설명한다.
  직접 표본과 유사 표본의 경기·투수 수를 함께 표시해 한 상대에게 편중되었는지 확인할 수 있게 한다.

## 예측을 추가하는 조건

A10의 고정된 모형을 해당 투수의 명시적 구종/코스 구성에 적용한 기대 반응만 후보로 삼는다.
선택 타자 효과를 사용하지 않은 리그 모형이라면 ‘이 타자 상대 예상’이라고 표시하지 않는다.
타자 효과를 추가한 모델은 별도 시간 검증과 소표본 축소를 통과해야 한다. 준비되지 않았으면
관측 비교만 제공하고 ‘최적 공략법’이나 자동 구종 추천을 만들지 않는다.

## 구현 순서

1. [x] `contracts/matchup.ts`, `persistence/matchup-repository.ts`에 직접/유사 표본을 분리한 조회 추가.
2. [x] 같은 원 구종·카운트·타석·5km/h 구간에서 고정된 구질 거리로 좁히는 별도 패널 추가.
3. [x] `/api/v2/analysis/matchups?season=...&pitcherId=...&batterId=...`와 선택 화면 구현.
4. [x] 직접/유사 범위·표본·동일 조건 리그 결과 및 근거 투구 제공.
5. [x] A10 고정 모형에 타자별 축소 효과를 추가하고 시간 검증을 통과한 목표만 제공.

## 검증과 완료 조건

직접 맞대결 0·1·다수 PA, 동일 이름/다른 ID, 특정 상대에 편중된 표본, 구질 계산 불가,
구속·구종 미상과 타석 좌우 불명을 테스트한다. 직접/유사 표본이 중복되는 경우 각 표의 의미를
유지하고 합산값은 제공하지 않는다. 기준 표준화가 평가 기간을 읽지 않는지 검증한다.
기술 통계가 근거 투구로 재현되고 확률 미준비 상태가 명확하면 첫 범위 완료다.

조회 개선: 리그 비교는 투구 fact와 canonical tracking link, PA eligibility만 읽는다. 선수 이름·키·
존이 필요 없는 조건 집계에 넓은 view를 확장하지 않는다. 경기별 조인 범위를 먼저 제한해 투구마다
세 테이블의 인덱스를 반복 탐색하는 비용을 줄이며, 직접/유사/타자 제외 리그의 응답 해시는 유지한다.

## 구질 거리와 타자 효과 구현

`/api/v2/analysis/matchups/model`은 별도 strict 계약을 사용한다. A10 학습 기간의 보정·포심 기준·
표준화를 고정하고 구속, 상대 가로·세로 위치, 도착 시간의 표준화 거리 RMS로 유사 공을 고른다.
반경 0.5/1/1.5를 과거 자료만 사용하는 2023·2024 검증에서 비교했다. 현재 자료에서는 단순 조건
필터보다 예측 오차를 안정적으로 낮추지 못해 반경 1의 탐색용 관측 결과로 표시한다. 예측 개선이
검증되었다고 표시하지 않으며 표본이 부족해도 반경을 확대하지 않는다. 비율별 분모 20 미만은
빈 값이고, 직접 맞대결 중복 수·경기·상대 투수 수·최대 투수 비중을 함께 제공한다.

기대 확률은 A10의 logit에 타자별 offset을 더한다. 합산 이항 log loss에 `λ × offset² / 2`를
추가하여 표본이 적을수록 리그 모형으로 축소한다. λ=20/100/500을 비교하고 두 시간 검증의
오차 감소, 경기 bootstrap 차이의 95% 구간 상한 < 0, 기존 하위집단 gate, 수렴을 모두 요구한다.
타자별 해당 목표 표본 20구·5경기 이상일 때만 표시한다. 2025는 선택에 사용하지 않은 평가다.

구종·타석 좌우·정규화 코스별 확률은 선택 투수가 실제 던진 구성에 선택 타자의 효과를 적용한
시나리오다. 다른 타자에게 던진 물리적 코스를 선택 타자의 신장으로 재투영한 예측은 아니다.
헛스윙은 스윙 조건부, 루킹 스트라이크는 지켜본 공 조건부이며 투구당 헛스윙 확률은 공별 곱의
평균이다. 모델/타자 이력이 없으면 숫자를 만들지 않는다. 자동 공략법 추천은 제공하지 않는다.

모델은 원천 manifest와 A10 모델 hash에 묶인 독립 파일로 저장한다. API는 매번 현재 원천을
검증하고 선택 투수·타자 입력만 worker에 전달한다. 학습 CLI와 실제 평가 수치는
[구현·검증 기록](../2026-09-20-matchup-angles.md)에 있다.
