## 디자인 특수성과 전체 인상

제공자 증거→원장→검증 불일치→선수 범위→정확한 typed event 재생이라는 흐름이 제품의 특수성을
만든다. 흰색·절제된 녹색 셸은 사용자가 정한 작업 도구의 성격에 맞다. 핵심 기회는 표현 장식보다
기록을 읽기 전 조건 선택 부담을 줄이는 데 있다.

잘 작동하는 세 가지는 다음과 같다.

- 대시보드 수치가 검토·적재 가능·저장 범위로 직접 이어지고 모바일에서도 2×2로 읽힌다.
- 차트 Home 선택이 정확한 경기·revision·이벤트 장면을 열고 확인 문구와 분석 복귀를 제공한다.
- 보정 상세가 선택 차단 문제와 적용 전후를 먼저 보여 주고 모바일에서 문서 스크롤로 이어진다.
