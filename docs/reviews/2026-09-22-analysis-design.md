# 분석 화면 재설계

2026-09-22. 기능·접근성 개선 이후에도 분석 화면은 큰 입력 폼, 같은 18열 표의 반복, 긴 원본 ID로
첫 화면을 채우고 있었다. `/analysis/pitch-location`의 실제 2025년 자료를 기준으로 정보 순서와
시각적 구성을 바꿨다.

## 화면 구성

- 선수와 시즌을 제목으로 표시하고 투구 수·Whiff%·CSW%·결정구 비율을 먼저 보여준다. 각 비율의
  분모/표본 수를 함께 표시하며 0분모는 기존처럼 `—`로 남긴다.
- 코스 지도에 존 테두리, 방향, 색상 범례를 추가하고 선택 코스의 지표를 옆에 표시한다. 색상은
  Whiff% 0–50%+의 고정 범위이며 20스윙 미만은 회색으로 구별한다. 수치 자체는 제한하지 않는다.
- 구종·카운트·타석 좌우와 타자의 구속대 비교를 한 패널에서 전환한다. 기본 표는 7열,
  `상세 지표`는 기존 18열이다. 전체 반응의 모든 지표도 펼쳐서 확인할 수 있다.
- 원본 투구·타석 목록은 접어서 제공하고 ID는 개별적으로 펼친다. 20개 단위 페이지 이동,
  정확한 revision의 재생 링크, 표본 누락/제외 안내를 유지한다.
- 코스·타자 반응·투구 움직임·선구안에 기본 조건/세부 조건 구조를 적용한다. 접힌 조건의 요약은
  현재 URL을 반영한다. 시즌 변경, 범위 유지, 조회 취소와 오류 정책은 기존 화면이 소유한다.
- 분석 전체의 제목·패널·표·메뉴 색상과 간격을 통일한다. 데스크톱에서는 코스 화면의 제목과
  필터가 나란히 놓이고 모바일에서는 세로로 배치된다. 좁은 표는 내부에서만 가로 스크롤한다.

## 모듈과 계산 경계

`AnalysisFilterBar`는 입력 배치만 공유한다. 조건의 의미나 상태를 공통 프레임워크로 이동하지
않는다. 범위 요약은 `analysis-scope-fields`의 표현 함수로 공유한다.

`pitch-location-panel`, `pitch-rate-table`, `terminal-batting-panel`은 각각 지도/근거, 비교 표,
타석 집계를 표현한다. API·컴파일러·DB 계약은 바꾸지 않았다. 지표 값은 서버 응답을 사용한다.
지도 선택 표본 필터링은 points/cell이 바뀔 때만 수행하고 페이지 이동에서는 재사용한다.
선택 표시와 비교 전환은 네트워크 요청을 발생시키지 않는다.

스타일은 `data-workspace="analysis"`와 분석 컴포넌트 클래스에 한정한다. 데이터 관리의 목록·교정
화면에 새 스타일을 적용하지 않는다. 추가 패키지, 이미지, 외부 폰트 요청은 없다.

## 검증

브라우저 플러그인으로 실제 2025년 투구의 지표·지도 선택·카운트 비교·근거 재생 링크를 확인했다.
1440px 데스크톱과 390/320px 모바일에서 확인했고, 접기/펼치기 상태에서 문서 가로 넘침을 점검했다.
자동 회귀는 접힌 초기 상태, 0분모, revision 링크, 비교별 단일 표, 18열 전환, 불필요한 요청 없음,
필터 URL 복원/유지, 시즌 변경, 21구 페이지 이동과 코스 선택 초기화를 다룬다.

- 전체 테스트: 178개 파일, 957개 통과. 별도 DSN이 필요한 DB 75개는 기본 suite에서 skip했다.
- 최종 공통 범위 요약·모듈 분리 후 관련 5개 suite의 32개 테스트도 통과했다.
- lint·format·타입 검사·schema check·전체 빌드 통과. 지도 대비 보완 후 웹 빌드도 통과했다.
- 격리 Compose E2E: 수집·교정·기록정정·DB·재생·분석·반응형·키보드·canvas·모델 worker와
  백업/복구 통과. 브라우저 오류 0개. 테스트 자원은 실행 후 정리했다.
- 지도 글자 대비: 고정 HSL 범위에서 검정/흰색을 전환하고 투구 수의 투명도를 제거했다.
  100,001개 비율값 검사에서 최소 대비 4.56:1, 회색 소표본 5.18:1을 확인했다.

운영 데이터는 읽기만 했다. 현재 UI는 `http://127.0.0.1:5173`의 로컬 미리보기이며 운영 서비스
재배포는 이 작업에 포함하지 않는다. 실행 로그는 `analysis/commit-preparation/20260922-analysis-design/`에 둔다.
