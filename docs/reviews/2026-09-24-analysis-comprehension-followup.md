`20`은 화면상의 주의 기준이다. 20 이상이라는 이유로 통계적으로 확실하다고 판단하지 않는다.
전년 비교는 시즌 전체와 현재 선택 기간의 관측 비교이며, 리그 평균이나 인과 효과가 아니다.

재생 자동 선택을 실제로 실행하면서 두 가지를 추가로 발견해 수정했다. React StrictMode의
effect 재연결에서 요청은 끝났는데 화면이 로딩에 남는 문제는 검증된 revision의 공유 query와
최종 선택 callback으로 해결했다. 고정 viewport grid가 점수판과 근거 카드를 과도하게 압축하는
문제는 내용 높이와 본문 스크롤을 유지하도록 바꿨다. 전체 frame의 canonical SHA-256과
경기/revision·순서·개수도 클라이언트에서 대조한 뒤 장면을 선택한다.

E2E 브라우저의 내부 서비스 주소 `http://web`는 secure context가 아니어서 Web Crypto를 사용할 수
없었다. 실제 배포와 동일한 `localhost` 주소로 테스트하며, 테스트 브라우저 안에서만 DNS를 격리된
web 컨테이너 IP로 연결하도록 수정했다. 검증을 생략하거나 브라우저 보안 설정을 완화하지 않는다.
또한 축소된 베이스 SVG의 원래 크기가 `scrollHeight`에 남으므로 카드 잘림 검사는 실제 렌더링된
자식 요소의 경계로 판정한다. PowerShell 5 실행용 스크립트의 UTF-8 BOM도 유지한다.
