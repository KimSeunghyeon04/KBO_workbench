# 프론트엔드 UI 점검과 개선

2026-09-22. 기존 녹색 계열의 작업 도구 디자인과 화면별 책임을 유지하면서, 실제 브라우저에서
확인한 탐색·상태 안내·키보드 조작 문제를 개선했다. 앞선 모듈화 변경 위에 적용한 UI 변경이다.

## 구현 경계

공통 탐색은 `AppShell`, 목록·상세의 반응형 포커스는 `OperationConsole`, 목록 키보드 동작은
`SelectableVirtualList`, 실제 탭의 키보드 동작은 `WorkspaceTabs`가 소유한다. 공통 빈 결과 안내와
scope 링크 직렬화만 작은 분석 모듈로 공유한다. API 응답 계약, 조회 계산, 원장·DB 쓰기 경로는
변경하지 않았다. 새 라이브러리나 별도 상태 저장소를 추가하지 않았다.

## 확인 방법

Context7으로 React Router의 NavLink와 TanStack Query v5의 비활성 조회 상태를 확인했다.
`isPending`은 요청이 없는 경우에도 참일 수 있으므로 초기 요청 진행에는 `isLoading`을 사용한다.

- [React Router 접근성](https://github.com/remix-run/react-router/blob/react-router@7.8.2/docs/how-to/accessibility.md)
- [TanStack Query 비활성 조회](https://github.com/TanStack/query/blob/v5.90.3/docs/framework/react/guides/disabling-queries.md)

브라우저 플러그인으로 운영 화면을 읽어 문제를 확인하고, 수정 코드는 localhost의 임시 Vite
미리보기에서 검증했다. 운영 데이터에 수집·보정·적재 명령을 실행하지 않았다. 실제 데이터의
대시보드·투구 움직임·DB 목록/상세·빈 매치업·날짜 오류를 확인했다. 390px 모바일과 1280px
데스크톱에서 메뉴·필터·페이지 가로 넘침을 점검했다. 320px에서도 메뉴 끝 항목으로 이동할 수
있음을 확인하고, 스크롤바가 차지하는 폭 때문에 생기던 body 최소 너비의 가로 넘침을 제거했다.
넓은 표는 기존 표 컨테이너 안에서 가로 스크롤한다.

자동 회귀는 메뉴 그룹/닫기/건너뛰기, 탭 키보드, 가상 목록 첫 선택, 모바일 포커스 복귀,
5개 화면의 무효 범위, 3개 화면의 빈 결과, 범위 유지 링크와 시즌 변경을 다룬다.
기존 대시보드·공식 기록 비교·공유 조회 테스트에도 변경된 동작을 반영했다.

## 검증 결과

- 전체 테스트: 178개 파일, 953개 통과. 웹 테스트 191개 포함. 별도 DSN이 필요한 DB 75개는 기본
  suite에서 skip했으며, 이번 작업은 DB 구현을 변경하지 않았다.
- lint·format·TypeScript·schema check·전체 빌드 통과. 마지막 최소 너비 CSS 보완 후에도 웹 빌드 통과.
- 격리 Compose E2E: 수집·교정·기록정정·DB·재생·분석·반응형·키보드·canvas·6종 모델 worker·재시작·
  백업/복구 통과. 브라우저 오류 0개. 고유 이름의 테스트 자원은 실행 후 정리했다.
- 브라우저 플러그인: 320/390/1280px, 메뉴 닫기와 포커스 복귀, 실제 목록 첫 행 선택과 목록 복귀,
  빈 매치업의 범위 유지 링크, 무효 날짜의 오류 단독 표시를 확인했다. 미리보기의 콘솔 오류 0개.

운영 서비스를 재배포하지 않았으며 수정 UI는 로컬 미리보기에서 확인했다. 실행 로그는
`analysis/commit-preparation/20260922-ui/`에 로컬 보존한다.
