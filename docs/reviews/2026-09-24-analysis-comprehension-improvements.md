# 분석 화면 해석 개선

2026-09-24. [점검 보고서](2026-09-24-analysis-comprehension.md)의 12개 항목을 반영했다.
Graft의 심볼·호출 관계로 소유 모듈을 확인하고 화면, 응답 계약, 기존 집계와 테스트를 함께 대조했다.

## 반영 내용

| 점검 항목           | 변경 내용                                                                                                                                         |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 구질 필터 범위   | 산점도·기대 차이 표에 적용되는 조건과 전체 구종을 사용하는 하단 패널을 구분했다. 기간 전체 구종 구성을 먼저 보여 주고 월별 표는 접었다.           |
| 2. 숨겨진 배합 조건 | 세부 조건을 접어도 첫·다음 구종, 카운트, 타석 좌우와 표본 조건을 볼 수 있다. 조건별 해제와 초기화를 제공한다.                                     |
| 3. 배합의 분모·부호 | Swing·Whiff·루킹 비율의 분모와 두 번째−첫 번째 차이의 부호를 설명한다. 각 평균 옆에 실제 계산에 쓰인 유효 쌍 수를 표시한다.                       |
| 4. 분석 존의 의미   | 시즌별 분석 기준과 역사적 심판 판정·ABS를 재현한 결과가 아니라는 점을 설명한다.                                                                   |
| 5. 조건 일치 비교   | 타자 반응→선구안 이동 시 구종·볼·스트라이크·타석 좌우를 유지한다. 공통 상황 조건과 각 분석의 표본 자격 차이를 구분한다.                           |
| 6. 시즌 변경        | 명시된 선수와 화면에서 암묵적으로 선택된 선수를 유지한다. 새 시즌에 자료가 없으면 빈 상태를 표시하며 다른 선수로 교체하지 않는다.                 |
| 7. 최근 변화        | 비교 기간·경기·투구 수와 최근 사용량 상위 3구종의 변화량을 먼저 보여 준다. 사용률은 %, 차이는 %p로 표시하고 95% 구간·소표본·자료 부족을 구분한다. |
| 8. 매치업의 루킹    | 관측 루킹/전체 투구와 모델의 루킹/비 스윙을 별도 지표로 설명한다.                                                                                 |
| 9. 모델 미평가      | 학습 모델이 없어 평가하지 못한 보정·기하 표본 수를 0건 대신 미확인으로 표시한다.                                                                  |
| 10. 모델 검증 연도  | 고정 연도 문구를 없애고 실제 학습 종료 시즌에 따른 검증 연도를 표시한다.                                                                          |

## 구현 경계

- 선수·기간 변경은 공통 scope 모듈이, 비교 링크의 공통 상황 조건은 별도 URL 도우미가 소유한다.
- 최근 변화의 단위·해석 문구와 요약 표시를 페이지에서 분리했다. 신뢰구간과 변화량은 서버 결과를 사용하며 브라우저에서 통계 계산을 반복하지 않는다.
- 요약에 표시할 구종은 최근 투구 수로 정한다. 변화가 큰 구종만 골라 보여 주지 않는다.
- 배합의 평균별 유효 표본 수는 `game-core`의 기존 평균 집계 루프에서 산출한다. 중간 배열 생성을 줄이고 평균의 누적 순서와 기존 분모를 유지했다.
- `PitchSequenceResponse.groups`에 `planeDistancePairs`, `planeTimeDifferencePairs`, `speedDifferencePairs`, `arrivalDistancePairs`를 필수 필드로 추가했다. 웹과 API를 함께 배포해야 하며 이전 API 응답을 조용히 허용하지 않는다.
- 원장·projection·sealed revision의 형식이나 해시 입력, 기본 기록 산식과 운영 데이터는 바꾸지 않았다.

## 검증

- 전체 테스트: 197개 파일·1,218개 테스트 통과. DSN을 지정하지 않는 기본 테스트의 PostgreSQL 통합 테스트 76개는 skip했다. DB 쓰기 경로는 변경하지 않았으며 별도의 통합/E2E 배포 검사는 실행하지 않았다.
- `pnpm lint`, `pnpm format:check`, `pnpm typecheck`, `pnpm schema:game:check`, `pnpm build` 통과. 공개 진입점 변경 후 `pnpm test:architecture` 37개도 통과했다.
- `pnpm performance` 통과: 558이벤트 compiler 평균 4.578ms, p95 6.227ms. 이 수치는 저장소 compiler 벤치마크이며 배합 화면의 응답 시간 측정치는 아니다.
- Graft 인덱스를 재생성했다. 빌드에서 발견한 브라우저 공개 API 누락을 수정하고 웹 TypeScript의 `browser` 조건을 Vite와 일치시켰다.

### 실제 데이터 브라우저 확인

최신 웹을 루프백 Vite 5173에서 실행했다. 일반 분석은 기존 8080 API를 읽고, 기본 기록은 기존 읽기 전용 5184, 신규 배합 응답은 별도 읽기 전용 5185 미리보기에 연결했다. 운영 프록시·컨테이너·볼륨을 교체하지 않았다.

- 손주영의 최근 3등판 151구와 이전 5등판 438구를 표시했다. 사용률 전환 시 직구 −5.8%p, 커브 +5.2%p, 슬라이더 +4.7%p 및 불확실/소표본 상태를 확인했다. 390px와 기본 데스크톱 너비에서 카드 배치를 확인했다.
- 김도영 반응 화면의 2스트라이크 조건이 선구안 링크와 접힌 조건에 유지됐다. 2024년 변경 후 ID 52605와 2,383구가 유지되고, 2020년에는 같은 ID의 자료 없음 상태를 표시했다.
- 손주영 배합의 활성 조건과 개별 해제·전체 초기화를 확인했다. 직구→커브 111쌍의 면·시간·구속 유효 표본은 111쌍, 도착 코스 표본은 104쌍으로 구분됐다.
- 슬라이더 선택 시 구질 필터의 적용 영역과 전체 구종 프로필, 월별 표의 접힘을 확인했다. 모델이 없는 상태에서는 기하·보정 평가를 미확인으로 설명하고 관측값만 표시했다.
- 손주영의 30경기·153이닝·ERA 3.41 및 G 안내, 김도영의 OBP 0.361·SLG 0.582·OPS 0.942와 반올림 안내, 주루 표의 기존 주자·초과 이동 설명을 확인했다.
- 임시 검증 탭의 오류·경고 로그는 없었다. 모델이 준비된 상태의 동적 검증 연도와 매치업 분모 문구는 회귀 테스트로 확인했다. 모든 선수·시즌 조합 또는 보조기술 전체를 확인한 것은 아니다.

검증용 5173 프로세스와 이번에 만든 5185 컨테이너는 종료했다. 이후 사용자 요청으로 웹과 API를 동일한 소스로 운영에 함께 반영했다. 기존 기본 기록 호환 문제를 포함한 실제 배포 결과는 [운영 배포 기록](2026-09-24-analysis-ui-deployment.md)에 정리했다.
